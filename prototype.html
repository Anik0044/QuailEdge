Prototype Design

A complete engineering breakdown of the QuailEdge prototype — featuring the conceptual 3D design and our actual working hardware.

🌡️ Smart Climate Control 💨 Ammonia Mitigation 💧 Water-Based Sanitation 🤖 Multi-Way Control 📱 Remote Monitoring

00 3D Concept Design

01 Physical Architecture & Enclosure

1

3D-Printed Enclosure

A custom-designed, apartment-friendly enclosure built using 3D-printed parts (Flamment) and assembled locally.

  • Flamment Material for durability
  • Compact Vertical Design fits small spaces
  • Open Mesh Sides for natural ventilation
2

Sensor Mounting

Sensors are strategically placed inside and outside the cage to accurately measure environmental conditions.

  • DHT22 (Temp/Humidity) inside the living area
  • MQ-135 (Gas) near the waste zone
  • ESP32-CAM mounted for live monitoring
3

Actuator Placement

Mechanical parts are positioned to perform cleaning and climate control without disturbing the birds.

  • Water Pumps for automated waste washing
  • Exhaust Fan for air circulation
  • Mist Humidifier for humidity control
4

Safety & Protection

Electrical components are kept away from the birds, and protective meshes are used where necessary.

  • Protective Mesh around bulbs and heat sources
  • Sealed Wiring to prevent pecking
  • External Power Supply for safety

02 Multi-Tier System Architecture

A

Edge Level (Sensing)

The physical layer where sensors collect real-time environmental data from the cage.

  • DHT22 monitors temperature & humidity
  • MQ-135 detects toxic ammonia gas
  • TTP229 allows manual touch control
B

Processing Level (Brain)

The ESP32 microcontroller acts as the brain, processing data locally using edge computing.

  • ESP32 WROOM32 for fast local decisions
  • Threshold-Based Logic (Temp > 26°C, Gas > 20ppm)
  • Works Offline without internet dependency
C

Application Level (User)

The user interface allowing farmers to monitor and control the system remotely.

  • Android App (Java/XML) with Bangla Voice Assistant
  • Web Dashboard hosted on Vercel
  • Live Camera Feed via ESP32-CAM

03 Core Functionality Workflow

①

Environmental Regulation

The system continuously checks if the environment is safe for the quails.

  • If Temp > 26°C, Exhaust Fan turns ON
  • If Humidity < 60%, Mist Humidifier turns ON
  • Ensures optimal growth and egg production
②

Automated Sanitation

A unique water-based cleaning system replaces bulky conveyor belts.

  • Triggers when Ammonia > 20 ppm
  • Water pump & pressure pump activate sequentially
  • Reduces gas levels within 15 minutes
③

Manual Override

Farmers can intervene at any time using the onboard touch sensor.

  • TTP229 Touch Sensor provides instant control
  • Turn fans, pumps, or lights ON/OFF manually
  • Useful for emergencies or maintenance
④

Data Telemetry

All sensor data is sent to the cloud for remote monitoring and analysis.

  • Live sync to Android App & Web
  • Latency is under 2 seconds
  • Alerts for unusual conditions
